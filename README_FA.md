# How to Become Bach — نسخه اولیه

این پوشه یک پروژه آغازین اندروید با Kotlin و Jetpack Compose است.

## امکانات نمونه اولیه
- انتخاب تعداد اکتاو از ۲ تا ۷ فقط در اجرای اول؛ انتخاب در تنظیمات گوشی ذخیره می‌شود.
- کتابخانه نمایشی شامل ۲۰ عنوان قطعه پیشنهادی.
- انتخاب فایل PDF، تصویر یا صوت از حافظه گوشی (فعلاً فقط انتخاب فایل؛ تحلیل خودکار هنوز پیاده‌سازی نشده).
- دو بخش نمایشی برای خطوط حامل و صفحه‌کلید.
- انتخاب حالت نت‌خوانی، Synthesia یا ترکیبی.

## ساخت APK
1. Android Studio را نصب کنید.
2. از مسیر File > Open پوشه `HowToBecomeBach` را باز کنید.
3. صبر کنید Gradle Sync کامل شود.
4. از منوی Build گزینه Build Bundle(s) / APK(s) و سپس Build APK(s) را انتخاب کنید.
5. فایل APK در مسیر `app/build/outputs/apk/debug/` ساخته می‌شود.

## نکته مهم
این پروژه فعلاً اسکلت و نمونه اولیه رابط کاربری است، نه نسخه نهایی تشخیص نت.
تشخیص نت از PDF/عکس به پردازش تصویر و Music Optical Recognition نیاز دارد.
تشخیص نت از MP3/WAV به جداسازی صداها و تخمین زیروبمی نیاز دارد؛ برای قطعات چندصدایی بهتر است ورودی MIDI هم پشتیبانی شود.
نت‌های کامل آثار دارای حق نشر باید از منبع دارای مجوز تهیه شوند. فهرست ۲۰تایی فعلی صرفاً عنوان‌های پیشنهادی است و فایل نت/ضبط همراه آن نیست.
